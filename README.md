# Clutch Disc Production System

A web-based production management and monitoring system designed to support manufacturing operations in the clutch disc production process.

This system integrates production monitoring, Production Management Control (PMC), and production reporting into a centralized platform to improve data management, operational visibility, and production performance tracking.

## Overview

The **Clutch Disc Production System** is developed to support production activities in a manufacturing environment by providing centralized access to production data and monitoring information.

The system aims to reduce manual data processing, improve data accuracy, and help production teams monitor production performance more efficiently.

## Features

* **Production Monitoring Dashboard** — Visualize production performance and achievement against production targets.
* **Production Management Control (PMC)** — Manage and record production data for manufacturing processes.
* **Production Reporting** — Generate and review production reports based on recorded data.
* **Production Data Management** — Organize and manage production records in a centralized database.
* **Role-Based Access Control** — Manage access to system features based on user roles.
* **Data Validation** — Support data consistency and reduce errors during data entry.
* **Responsive Interface** — Access the system through different screen sizes.

## Production Processes

The system is designed around the clutch disc manufacturing process, including:

1. Preforming
2. Hot Press
3. Drilling

The supported production stages may vary depending on the system configuration and implementation.

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/strvntrl/clutch-disc-production-system.git
```

### 2. Navigate to the Project Directory

```bash
cd clutch-disc-production-system
```

### 3. Configure the Database

* Make sure PostgreSQL is installed and running.
* Create a new database for the application.
* Import the required database schema and initial data.
* Configure the database connection according to your local environment.
#ord

### 5. Run the Application

Start the application using your configured local PHP development environment or web server.
